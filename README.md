## Build

Assuming you have a valid access token for https://github.com/hallowelt/webservice-wire.git stored in `~/github-token.txt`, you can run

```bash
GITHUB_TOKEN=$(cat ~/github-token.txt) \
docker build \
	--secret id=GIT_AUTH_TOKEN.github.com,env=GITHUB_TOKEN \
	-t bluespice/wire:latest .
```

## ENV vars

| Key                   | Description                                                                                                                        |
|-----------------------|------------------------------------------------------------------------------------------------------------------------------------|
| `WIRE_API_KEY`   | A random string to serve as API key for HTTP communication with the [`mwstake/mediawiki-component-wire`](https://github.com/hallowelt/mwstake-mediawiki-component-wire)                              |
| `WIRE_WIKI_BASE_PATH` | Base path for the MediaWiki installation                                                                                          |
| `WIRE_LOG_LEVEL`      | (optional) level of logging, defaults to `warning`, other options are `info`, `debug`, `error`                                     |
| `WIRE_PORT`           | (optional) port to run application on (must be exposed)                                                                            |
| `WIRE_TOKEN_SALT`     | A salt to sign/unsign tokens generated by [`mwstake/mediawiki-component-token-authenticator`](https://github.com/hallowelt/mwstake-mediawiki-component-token-authenticator)                     |
